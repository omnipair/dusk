# One-off legacy market retirement

This is an isolated production build for
`7xf68VEvMtLJ2Up5zVZdA161uH1yNkTFYgDFhNUSwkM7` only. The normal build keeps
its normal ABI and behavior. Enabling `production,legacy-retirement` replaces
normal trading, governance and transfer-hook entrypoints with the retirement
ABI. It does not publish an SDK or change program IDs.

The authority attests the economic manifest generated by the exact deployed
layout-17 binary. On chain, the retirement build enforces complete frozen
receipt supply, full frozen custody funding, fixed beneficiaries, safe token
recipients, immutable amounts, rent destinations and replay protection. The
authority's attestation remains responsible for curve ordering, normal fees
and each wallet's final net entitlement. Review the quote, complete account
catalog and program together.

## Approved economics

- Return final net OMFG/META after debt, gains/losses and normal fees.
- Retain at least 99% of each reviewed token quote, with an integer ceiling.
- Include forced position settlement; no treasury-funded compensation.
- Allow immediate terminal junior settlement after all legacy personal claims
  are cleared, retaining the ordinary 0.5% junior exit fee in the quote.
- Send the approved permanent seed, protocol fees and rounding residue to
  `8s6Jdoh7tgUqmU3D2EmpNJHSvuN5U4NybpLAdsiMitwB` after every user is paid.

## State transitions

1. **Freeze.** The temporary binary already rejects normal entrypoints. An
   authority-signed `freeze_legacy_market` additionally records the exact clock,
   original market digest, complete receipt mint/account bytes and all eight
   underlying vault balances. Receipt balances must reconcile to every mint's
   supply, including protocol custody. Ownership and interest cutoff therefore
   survive later receipt burns, account housekeeping and review delays.
2. **Begin funded settlement.** After reviewing the frozen old-binary quote,
   `begin_legacy_retirement` commits all five payout plans and personal-account
   evidence hashes. The complete frozen custody budget funds those claims.
   The program consolidates only that budget and replaces the old market
   discriminator with a permanent `RetiredLegacyMarket` tombstone. This is the
   irreversible boundary. A restored old binary cannot redeem old positions or
   receipts, and the account is never closed or reinitialized.
3. **Clear personal state.** Anyone may submit the exact, hash-bound account
   group for an owner. All 26 known position, delegation, junior-exit and yield
   accounts are terminally settled into the funded claims and closed; their
   actual SOL rent returns to that owner. Every owner group must be complete
   before any token payout, including junior principal.
4. **Pay users.** Permissionless submissions pay the immutable per-owner token
   amounts. The destination must have the fixed owner and mint, no spending
   delegate, and no foreign close authority. Both asset legs and the paid bit
   commit atomically. A rejected recipient remains unpaid and can retry with a
   safe account owned by the same beneficiary. There is no claim deadline.
5. **Finish.** Treasury receives the fixed remainder only after all five user
   payments and rent groups are complete. Unsolicited post-cutoff token
   transfers remain outside that approved budget. The completed state and
   tombstone remain permanently available for verification.

The old receipt tokens are not burned by administrative fiat. Their redemption
right ends at the tombstone and funded settlement commitment; owners retain
their ordinary ability to burn/close their own obsolete token accounts.
Protocol metadata, receipt mints/vaults, income epochs and the tombstone retain
their protocol rent. They are separate from the personal rent returned above.

The empty delegate order in `scope.json` contains no staged token funds. Its
owner retains ordinary cancellation and rent recovery after the successor
upgrade. The local test executes that cancellation against the actual
successor delegate binary. No additional delegate authority is introduced.

## Quote and execution evidence

The quote must use the verified old executable and its IDL, the immutable
freeze clock/receipt snapshot and frozen underlying budget. Its provenance
must distinguish the actual temporary deployment from the old executable used
to evaluate economics. Never label a reconstructed quote model as an RPC bank,
change active indexer pins to make it decode, or count hypothetical swaps as
actual volume.

The current lifecycle test accepts the existing exact-binary quote report and
captured source bank, emulates the code upgrade locally, and exercises the real
retirement SBF. The five mandatory paths are unsigned local inputs:

```sh
node scripts/retirement/rehearse.mjs \
  SOURCE_BANK_REPORT QUOTE_REPORT RETIREMENT_SBF RETIREMENT_IDL NEW_REPORT
```

Append the successor Dusk SBF/IDL and delegate SBF/IDL to check the full switch,
existing futarchy account compatibility and retained owner cancellation.
The tool loads no signing keys, has no RPC client, and cannot send a network
transaction. Its unsigned test transactions include failure scenarios and
must never be used as an execution manifest. Raw bank/recipient evidence stays
in local release storage.

The current local rehearsal uses the fresh 95-account finalized source at slot
470926403. It clears both loans and all five leverage positions in the reviewed
order, distributes both assets to five owners, returns personal rent and proves
custody conservation. It also checks immutable cutoffs, incomplete batches,
unsafe recipients, second-leg rollback, restart/resumption, duplicate actions,
post-cutoff donations, stale-freeze rejection and old-binary rollback. This is
preparation evidence, not an already frozen or authorized mainnet payout.

## Unsigned release candidate

Generate the isolated IDL and binary with the exact committed source:

```sh
yarn release:build-retirement
```

Alternatively dispatch `release-build.yaml` with a full reviewed commit and
`profile=legacy-retirement`. It uses the pinned verifier/builder image and
uploads `dusk-retirement-release-<commit>`. Its manifest disables SDK
publication and requires an exact-binary local frozen-state rehearsal. A build
artifact alone grants no execution authority. The normal production profile
continues to build and test both normal programs.

## Successor upgrade guard

The original deployment runner intentionally refuses changed code. The
successor has a separate scoped upgrade runner:

```sh
node scripts/release/upgrade.mjs plan SUCCESSOR_BUNDLE RETIREMENT_BUNDLE
node scripts/release/upgrade.mjs preflight SUCCESSOR_BUNDLE RETIREMENT_BUNDLE
```

It verifies mainnet, exact approved prior code/IDLs, the permanent tombstone,
all payout/rent bits, zero remaining retirement budget and closure of all known
personal accounts. An additional legacy claim blocks the first upgrade.
Preflight reports peak buffer funding, extension rent, IDL funding and payer
shortfall. The later `upgrade ... --execute` path uses only the checked local
encrypted-volume signer, supports exact-code resumption, uploads each IDL after
its program, and verifies both final programs and authorities. Stable SDK
publication and remote source attestation remain separate protected steps.
