# Historical analysis notice

This directory is preserved as a historical, sealed benchmark snapshot. Its
models, locked profiles, evidence, and conclusions must be interpreted within
that frozen scope.

Specifically, the snapshot evaluates:

- the StableSwap-derived DH2 model used by this analysis;
- configured fee caps in that historical model; and
- selected locked profiles in which dynamic fees were disabled.

It does **not** rank or validate the current Dusk concentrated-AMM runtime
design: a hybrid invariant with an exact-CPMM outer region and an uncapped
outward divergence fee. Results in this directory must not be presented as
evidence for or against that current runtime without a new, implementation-
matched benchmark.

The sealed inputs, engine-hashed sources, result files, generated artifacts,
and portable report remain unchanged so the historical analysis stays
reproducible.
