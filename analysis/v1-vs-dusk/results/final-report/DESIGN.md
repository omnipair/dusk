# Report Design

- Surface: self-contained technical HTML report with PDF conversion.
- Reading path: result, evidence integrity, representativeness, calibration failure, definitions, methods, limitations, action.
- Charts: three full-width horizontal comparisons using one blue root and one orange root; exact tables remain neutral.
- Accessibility: no color-only distinctions; all charts retain semantic tables and direct values.
- Mobile: single-column block order; long market labels are abbreviated with full keys in tooltips and evidence.
